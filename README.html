Model Profiles

🔗

The model is described by a profile in models/: where to download it (Hugging Face repository and file), its context per slot, the number of slots, the longest answer, the prompt cache, the default CPU/GPU split for models with experts, sampling, and how its reasoning is switched off (REASONING).

The default profile (models/default) is for general chat and writing. It handles basic conversation, translation, and code assistance.

Current Model: Qwen-7B-Chat

PropertyValue
FormatGGUF (q4_K_M)
VRAM~5.5 GB (fits in 8 GB)
Context64K per slot
Slots2
API Endpointhttp://127.0.0.1:8081/v1

To use another model:

  1. Add a profile in models/: copy the default and change values.
  2. Set MODEL_PROFILE="<name>" in ~/.config/localllm/local.env.
  3. Run install/llama.sh, then stop/llama.sh && start/llama.sh.

Installation

🔗

Install the model from Hugging Face:

bash install/llama.sh

This downloads the model files to ~/LocalLLM/models/, checking free space before transferring. No copy is kept elsewhere.

Reinstalling from Scratch

pkill -f llama.cpp
rm -rf llm-data/
bash zram-setup-old.sh

Then restore configs from backup.

Starting and Stopping

🔗

The server runs as the systemd service localllm-llm and is only reachable locally through its OpenAI-compatible API.

Quick Commands

# Start the server
bash start/llama.sh

# Stop the server
bash stop/llama.sh

# Restart
bash stop/llama.sh && bash start/llama.sh
▼

Memory Configuration

🔗

The server uses 6 GB of RAM by default. Adjust runArgs in the config:

"runArgs": ["--memory=6g"]

For JVM-based tools: JAVA_TOOL_OPTIONS=-XX:MaxRAMPercentage=60

For Node.js builds: NODE_OPTIONS=--max-old-space-size=3072

Pi Integration

🔗

The server is served as local — Pi and its model settings always ask for that name, so changing the model touches none of them.

File Watching

Pi watches the repo directory for file changes. When you edit a file, Pi picks up the new content automatically.

Subagents & Todo Lists

For long-running tasks, Pi uses subagents to parallelize work. The todo list tracks stages across subagent sessions.

Sandbox

Pi runs code execution in an isolated sandbox by default. Network access is disabled unless explicitly granted.

Backup & Restore

🔗

Backups are versioned by date in backups/. Each backup includes configs, profiles, and SSH keys.

Restoring a Backup

tar xzf backups/2023-04-12.tar.gz

Model files are not included in standard backups — copy them separately.

Automatic Backups

An encrypted rsync job pushes daily backups to a remote server at 2 AM via cron.
